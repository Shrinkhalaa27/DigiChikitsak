# Dataset notes

The symptom dataset supplied with the project has 349 rows and 114 unique disease labels. A model can be trained for a reproducible machine-learning demonstration, but the small number of examples per label means its predictions are not reliable clinical diagnoses. The application intentionally presents results as experimental pattern matches.

The virtual patient dataset has 117 rows and labels `Non frail`, `Pre-frail`, and `Frail`. It is included for transparent future work. This version does not claim to use it for diagnosis or a validated frailty prediction.
